# Install with Foreman (recommended)

Foreman is the recommended install path. It pins Lithos per project, keeps
CI and local machines aligned, and already fits most Roblox toolchains.

```toml filename="foreman.toml"
[tools]
lithos = { source = "siriuslatte/lithos", version = "<version>" }
```

Pick the current version from the
[releases](https://github.com/siriuslatte/lithos/releases) page.

If you need Foreman itself, see
[Getting started](/docs/getting-started#1-install-lithos).

# Manually download from releases (simplest)

If you just want the binary, download the latest build from the
[releases](https://github.com/siriuslatte/lithos/releases) page and place
it on your `PATH`.
