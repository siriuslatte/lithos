# Code of Conduct

This repository expects respectful, technical, good-faith collaboration in
issues, pull requests, discussions, reviews, docs work, and other project
spaces.

## Expected behavior

- be direct, factual, and constructive
- assume good intent until there is evidence otherwise
- keep review feedback focused on behavior, code, docs, and reproducible facts
- respect different experience levels and leave room for questions
- disclose constraints, risks, and uncertainty clearly

## Unacceptable behavior

The following behavior is not acceptable in this repository:

- harassment, intimidation, or personal attacks
- discriminatory or exclusionary language
- sexualized language or unwanted sexual attention
- doxxing, threats, or sustained hostile behavior
- bad-faith derailment, dogpiling, or deliberate misrepresentation of another person's work
- publishing private or security-sensitive information without permission

## Scope

This code of conduct applies to repository-maintained spaces and project
interactions, including issues, pull requests, review threads, discussions,
documentation contributions, and release-process conversations.

## Reporting

If you experience or observe behavior that violates this code of conduct,
contact the repository owner, [@siriuslatte](https://github.com/siriuslatte),
through a private contact method currently published on that GitHub profile.

Do not use public issues or pull requests for conduct reports that would expose
private details.

## Enforcement

Enforcement is handled on a best-effort basis by the repository maintainer.
Actions may include content removal, conversation locks, blocking further
participation, or other moderation steps judged necessary to protect the
project's working environment.
